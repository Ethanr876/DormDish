# DormDish
DormDish is an interactive AI web app that teaches college students how to plan and cook cheap, balanced one-pan dinners using only a dorm or apartment kitchen. Instead of following recipes, learners practice a simple formula (base + protein + veg + flavor) until they can build their own meals under $4 a serving.
